# Context Builder

An interactive learning activity that teaches one applied AI skill: **AI output is only as good as the context you give it.**

**Live:** [asadravian.github.io/context-builder](https://asadravian.github.io/context-builder/)

## What the learner does

1. **Real scenario:** read a realistic workplace request, such as a customer ticket.
2. **Prompting with context:** switch on four prompt ingredients (Role, Context, Tone and Goal) and watch the AI reply improve. A four-point quality check shows why each change matters.
3. **Human in the loop:** review a draft that used all four ingredients and catch the one line that breaks policy before it is sent.

The activity takes about 10 minutes and ends with a reusable R-C-T-G prompt template.

## Scenarios

The method stays the same while the content changes for each audience:

- **Customer support:** a repeat complaint about a damaged order
- **Team leader:** preparing feedback for a team member who has missed deadlines
- **HR adviser:** an employee question about carrying over holiday

## Facilitator view

A trainer view shows what the current learner did: which ingredient they chose first, the order they added them, time to complete and attempts at the final check. It also includes an example cohort summary, clearly marked as sample data, to show how the results could shape the next session.

## Design choices

- **Scripted, not live AI:** every learner sees the same result, and no AI account or licence is needed.
- **Built from real work:** each scenario reflects a task people actually do, not a generic AI example.
- **Safe by design:** practice data only. The activity does not store or send any learner data.
- **Simple to share:** one self-contained HTML file that works on desktop and mobile.
